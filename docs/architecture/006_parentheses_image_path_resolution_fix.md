## 1. Executive Summary & Symptom Analysis

### 1.1 Symptoms
1. **Live Preview Rendering Failure:**
   When previewing Markdown documents containing image paths with parentheses in directory or file names—such as `./Vanguard_Engineering_Impact_(4)_assets/pdf_image_p1_1.png` (commonly generated by Windows when downloading or saving duplicate files)—the Live Preview pane rendered blank skeleton loading bars instead of images.
2. **Document Conversion Fallback Failure:**
   When converting Markdown containing such image paths to PowerPoint (`.pptx`), Word (`.docx`), or HTML (`.html`), the converter failed to detect image tokens. Consequently, plain text tokens like `![Image 1](./Vanguard_Engineering_Impact_(4)_assets/pdf_image_p1_1.png)` were inserted onto slides/documents as text paragraphs instead of embedded pictures.
3. **PyInstaller Frozen Build Dependency Check Error:**
   The packaged executable emitted a missing dependency dialog (`Required package 'pdfplumber, markdown-pdf' is missing`) because `markdown_pdf` was omitted from PyInstaller's `collect_all()` and `hiddenimports` configuration.

---

## 2. Root Cause Analysis

### 2.1 Regex Parentheses Truncation Bug (Primary Cause)
Across the codebase, image link extraction relied on the standard regex pattern:
```python
# Flawed regex pattern
image_pattern = r"!\[([^\]]*)\]\(([^)]+)\)"
```
When evaluated against a path containing parentheses such as:
`![Image 1](./Vanguard_Engineering_Impact_(4)_assets/pdf_image_p1_1.png)`

The negated character set `([^)]+)` matched up to the **first closing parenthesis `)`** inside `(4)`.
- **Extracted URI:** `./Vanguard_Engineering_Impact_(4`
- **Truncated Suffix:** `_assets/pdf_image_p1_1.png)`

Because the extracted URI was truncated, file path checks (`os.path.exists`) returned `False`. In `pptx_module.py`, `re.match(r"^!\[([^\]]*)\]\(([^)]+)\)$", line)` failed to match the line ending `)$`, causing the parser to treat image tokens as standard text paragraphs.

### 2.2 Unnormalized Relative Path & Missing Base Directory Lookup
1. **Unnormalized Paths:**
   On Windows, combining a base path and a relative path with `./` (e.g. `C:\Users\Admin\Desktop\./assets/img.png`) without calling `os.path.normpath(os.path.abspath(...))` caused file existence checks (`os.path.exists`) to return `False`.
2. **Draft Session Disconnect:**
   When the app restores draft content from `draft_autosave.md` into the Editor Buffer, `self.state.in_path` is `None`. `MediaAssetManager.resolve_uri()` lacked a fallback search in working directories or Desktop subfolders (e.g. `Desktop/Test/<assets>/`), returning the unresolved relative URI.

### 2.3 PyInstaller Specification Omissions & Over-Aggressive Excludes Bug
1. `markdown_pdf` was omitted from PyInstaller's `collect_all()` loop and `hiddenimports`.
2. Standard library modules such as `cryptography` and `unittest` were explicitly listed in PyInstaller's `excludes=[...]` array in `Document Converter.spec`.
   - Excluding `cryptography` caused `pdfminer` (used by `pdfplumber`) to crash with `ModuleNotFoundError: No module named 'cryptography'`.
   - Excluding `unittest` caused `pyparsing` (used by `httplib2` -> `plantuml` -> `markdown_pdf`) to crash with `ModuleNotFoundError: No module named 'unittest'` when exporting Markdown to PDF (`MD -> PDF`).
   - Cleaned up `excludes=[...]` array to keep standard library utilities required by third-party dependency trees.

## 3. Technical Solution & Implementation Details

### 3.1 Robust Image Regex Pattern
Replaced the simplistic `([^)]+)` pattern across all modules with a robust regex pattern that validates file extensions, URLs, or `@media/` tokens while allowing parentheses inside directory and file names:

```python
# Robust Image Regex Pattern
image_pattern = r"!\[([^\]]*)\]\((.+?\.(?:png|jpg|jpeg|gif|svg|webp|bmp|ico)|https?://\S+|@media/\S+?|[^\n)]+)\)"
```

### 3.2 Smart Fallback Lookup in `MediaAssetManager.resolve_uri`
Updated `resolve_uri(self, uri: str, base_dir: str = None) -> str` in [`src/services/media_asset_manager.py`](file:///c:/Users/Admin/Desktop/DocumentConvertTool/src/services/media_asset_manager.py) to perform normalized path checks and fallback searches across Desktop and CWD subdirectories:

```python
def resolve_uri(self, uri: str, base_dir: str = None) -> str:
    if not uri:
        return uri

    # 1. Virtual @media/ token resolution
    if uri.startswith("@media/"):
        filename = uri[7:]
        primary_path = os.path.normpath(os.path.join(self.get_session_dir(), filename))
        if os.path.exists(primary_path) and os.path.isfile(primary_path):
            return primary_path

        if os.path.exists(self.cache_dir):
            for root, _, files in os.walk(self.cache_dir):
                if filename in files:
                    found_path = os.path.normpath(os.path.join(root, filename))
                    if os.path.isfile(found_path):
                        return found_path
        return primary_path

    # 2. Local disk file path resolution
    if not uri.startswith(("http://", "https://", "data:")):
        norm_uri = os.path.normpath(uri)
        if os.path.exists(norm_uri) and os.path.isfile(norm_uri):
            return norm_uri

        if base_dir:
            candidate = os.path.normpath(os.path.abspath(os.path.join(base_dir, uri)))
            if os.path.exists(candidate) and os.path.isfile(candidate):
                return candidate

        # Smart Fallback: Check relative to CWD, Desktop & immediate subdirectories
        clean_rel = uri.lstrip("./").lstrip(".\\")
        search_bases = [
            os.getcwd(),
            os.path.dirname(os.getcwd()),
            os.path.expanduser("~/Desktop"),
        ]
        for sbase in search_bases:
            if sbase and os.path.exists(sbase):
                cand = os.path.normpath(os.path.join(sbase, clean_rel))
                if os.path.exists(cand) and os.path.isfile(cand):
                    return cand
                try:
                    for item in os.listdir(sbase):
                        sub_dir = os.path.join(sbase, item)
                        if os.path.isdir(sub_dir):
                            cand_sub = os.path.normpath(os.path.join(sub_dir, clean_rel))
                            if os.path.exists(cand_sub) and os.path.isfile(cand_sub):
                                return cand_sub
                except Exception:
                    pass

        # Search by filename across AppData cache
        base_name = os.path.basename(uri)
        if os.path.exists(self.cache_dir):
            for root, _, files in os.walk(self.cache_dir):
                if base_name in files:
                    found_path = os.path.normpath(os.path.join(root, base_name))
                    if os.path.isfile(found_path):
                        return found_path

    return uri
```

## 6. Maintenance Guidelines
When adding new document import/export modules or modifying image token parsing in the future:
1. Always use the robust image regex pattern: `r"!\[([^\]]*)\]\((.+?\.(?:png|jpg|jpeg|gif|svg|webp|bmp|ico)|https?://\S+|@media/\S+?|[^\n)]+)\)"`.
2. Never assume image paths omit parentheses or spaces.
3. Always normalize combined file paths with `os.path.normpath(os.path.abspath(path))`.
4. Ensure third-party modules are added to `Document Converter.spec`'s `collect_all()` loop.
