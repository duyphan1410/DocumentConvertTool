# 🏛️ Release Notes — v1.5.3: Auto Draft Restoration UX & Smart Overwrite Modal

**Release Date:** August 10, 2026  
**Project:** Document Converter Tool  
**Version:** `v1.5.3`  
**Branch:** `feat/duy-10082026-auto-draft-loading-ux`  

---

## 🚀 Key Highlights & New Features

### ⏳ 1. Smooth LoadingView & Asynchronous Draft Restoration
- **Instant Workspace Transition (~0.4s)**: Restores auto-saved text draft and opens the `EditorView` immediately without UI stuttering or thread freezes.
- **60fps Fluid Spinner**: Dedicated `LoadingView` featuring a non-blocking `ft.ProgressRing` spinner.
- **Background Live Preview Rendering**: Heavy Base64 image encoding for PDF slides runs asynchronously (`process_markdown_media_async`), showing a clean header indicator: `⏳ Loading preview...`.

### 📋 2. Smart Overwrite Modal with 1-Click Auto-Rename
- **1-Click `[Save As New File (filename_1.md)]`**: Automatically computes an available non-colliding filename when saving.
- **Exact Filename Focus & Selection**: Clicking "Cancel" on the file overwrite modal automatically highlights ONLY the filename string (e.g. `Resume` in `C:\...\Resume.docx`), retaining the directory path and extension so users can type a replacement filename instantly.

### 🌐 3. Full Path Bar Internationalization (i18n)
- Unlocked direct text input for both source and destination path fields.
- Dynamic locale-aware labels: **`File .ext` / `Save .ext`** (English) and **`Tệp .ext` / `Lưu .ext`** (Vietnamese).

### 🛠️ 4. Version Sync & PyInstaller Spec Update
- Bumped application version to **`1.5.3`**.
- Added `src.ui_flet.views.loading_view` to `hiddenimports` in `Document Converter.spec` to guarantee 100% PyInstaller standalone `.exe` build compatibility.
- Expanded project `product_roadmap.md` for upcoming formats (PowerPoint `.pptx`, YouTube URL Transcriber, JSON/YAML Data, Whisper AI Speech-to-Text, EPub eBooks).
