## 🚀 Highlights & Key Features

### 📊 1. Bi-directional PowerPoint Plugin Engine (`PPTX ↔ MD`)
- **PowerPoint Extraction (`PPTX ➔ MD`)**:
  - Extracts Slide layout, Titles (`## Title`), body paragraphs, and ordered lists **Numbering (`1. `, `2. `)** from OpenXML `a:buAutoNum`.
  - Parses Chart data (Column, Bar, Pie, Line) into Markdown Tables with footprint metadata `<!-- chart: type title="..." legend="..." -->`.
  - Extracts slide images into `@media/` directory and preserves Slide Notes pane content at the bottom of the slide.
- **PowerPoint Generation (`MD ➔ PPTX`)**:
  - Default **16:9 Widescreen (13.333" x 7.5")** layout.
  - Reconstructs Native PowerPoint Charts from Markdown tables and footprint comments.
  - Automatically adds padding for Legend boxes (`include_in_layout = False`), resolving label overlaps.
  - Preserves ordered list numbers `1. `, `2. ` and bullet dots `•  ` in Slide Notes.

### 🛡️ 2. Automatic Slide Content Overflow Protection (`Ensure Space`)
- Automatically calculates total content height (`top_offset`) before drawing elements (Charts, Tables, Images, Paragraphs).
- When content height exceeds slide bounds (`slide_height - 0.8"`), the system automatically creates a Continuation Slide and moves remaining content to the top (`top = 0.8"`), ensuring 100% data preservation without content cutoff.

### 🎯 3. Universal Dynamic Window Focus & Win32 `AttachThreadInput` Elevation
- **100% Pure Dynamic Matching**: Zero hardcoded application/browser lists.
- **Dynamic HTML Title (`<title>{filename}</title>`)**: `HTMLModule` renders output file basename in HTML `<title>` tag, allowing 100% of Web Browsers (Chrome, Edge, Firefox, Brave, Opera, Vivaldi, Arc...) to automatically display output filenames on window title bars.
- **Thread Input Attachment (`AttachThreadInput`)**: Bridges active foreground input context with browser processes, eliminating Windows `ForegroundLockTimeout` taskbar flashing.
- Combined `BringWindowToTop`, `AttachThreadInput`, `SetForegroundWindow`, and `SwitchToThisWindow` to grant active foreground focus instantly.

### 🛠️ 4. System Bug Fixes & Patches (v1.6.2 Patch & Focus UX Enhancements)
- **Universal Win32 Target Window Focus**:
  - Integrated simulated `ALT` key tap (`keybd_event VK_MENU`) to bypass OS `ForegroundLockTimeout` for pre-existing background processes (`explorer.exe` and `excel.exe`).
  - Added explicit target PID privilege authorization via `AllowSetForegroundWindow(target_pid)`.
  - Enforced `SW_MAXIMIZE` (3) for automatic **Full Screen Window Expansion** on launch.
  - Replaced `HWND_NOTOPMOST` with `HWND_TOP` (0) to preserve natural Z-order and Alt+Tab task switching.
- **Conversion UX Progress Bar & Audio Feedback**:
  - Automatically displays 60fps `ProgressBar`, updates status text to Amber `status.converting`, and locks controls during conversion.
  - Integrated system audio completion chime via `winsound.MessageBeep(winsound.MB_OK)`.
  - Added floating green `SnackBar` toast notification with accurate execution timing.
- **PPTX Text Overflow & Pagination**: Implemented automatic line chunking pagination across continuation slides for long Markdown text blocks.
- **PyMuPDF TOC Hierarchy Fix**: Automatically normalizes TOC hierarchy level starting at level 1 when Markdown documents begin with `## Heading 2`, avoiding PyMuPDF `ValueError`.
- **Word Exporter `UnboundLocalError` Fix**: Resolved `src_url` variable scope issue during `.docx` export.
- **Flet 0.80+ UI Compatibility**: Updated `MessageDialog` & `SnackBar` controls for Flet 0.80+ compatibility.
- **Auto-Draft Mode Filtering**: Restored conversion mode dropdown filters by file extension upon draft recovery on app startup.
