## ✨ What's New in v1.9.2

### ⏱️ Recent Files & Folders History & 2-Column Welcome Studio Dashboard
- **Smart LRU Activity Store (`%APPDATA%\DocConvert\recent_history.json`)**:
  - Automatically tracks recently opened documents and project folders with distinctive color-coded icons (Word, Excel, PDF, Markdown, Media, Folder).
  - Built-in **Pinning (`📌 Pin`)**, individual removal (`✖`), and complete clearance (`Clear All`).
  - Real-time **Search Filtering** and **Category Tabs** (`All` / `Files` / `Folders`).
  - Proactive missing/moved file detection with visual warning badges.
- **Overhauled 2-Column Welcome Studio Dashboard (920px Modern Layout)**:
  - Clean 2-column layout: Left column (Quick Actions, Branding, physical `<kbd>` shortcut badges), Right column (Interactive Recent History activity feed).
  - **Home Button (`ft.Icons.HOME_ROUNDED`)** in Activity Bar: Quickly navigate back to the Welcome Dashboard at any time without losing open editor tabs.
- **Multi-Window Support (`Ctrl+Shift+N`) & Focus Elevation**:
  - Launch independent workspace application instances via `Ctrl+Shift+N`.
  - Win32 `SetForegroundWindow` and `AttachThreadInput` integration ensures immediate foreground elevation.
  - Dedicated **Close Workspace** button in the File Explorer header.

### 👁️ OCR Scanned PDF Engine & Scroll Synchronization
- **Scanned PDF to Markdown Mode (`pdf_scan_to_md`)**:
  - Optical character recognition engine automatically extracts and formats text from image-only / scanned PDF pages into structured Markdown.
- **2-Pass Frame Layout Scroll Lock**:
  - Locks Live Preview scroll position during image resizing and alignment adjustments, preventing page jumping in long documents.

---

### 🧠 AI Model Hub & Offline Speech Transcriber (Whisper AI)
- **100% Offline Speech Recognition (Zero Data Leakage)**:
  - Powered by `faster-whisper` and `CTranslate2` (`int8` quantization) for high-speed local transcription without Internet access.
  - Supports diverse audio and video containers: `.mp3`, `.wav`, `.m4a`, `.flac`, `.aac`, `.ogg`, `.mp4`, `.mkv`, `.avi`, `.mov`, `.webm`.
  - Integrated **Silero Voice Activity Detection (VAD)** for clean `[mm:ss]` timestamped paragraph segmentation and audio normalization (-0.9 dBFS).
- **Standalone AI Model Hub & Marketplace**:
  - Manage and download Whisper models (`tiny`, `base`, `small`, `medium`, `large-v3`) located at `%APPDATA%\DocConvert\models\`.
  - Automated hardware scanner (CPU Cores, RAM, NVIDIA CUDA GPU VRAM & Drivers) recommending the optimal AI model for your PC.
  - 2-layer verification (SHA256 checksums + Runtime model loading) with 64KB chunked downloads and instant cancellation.
- **Background Transcription & Smart Tab Integration**:
  - Non-blocking background worker with spinning Activity Bar indicator.
  - Spawns dedicated Workspace Tabs automatically upon completion with autosaved drafts.

- **Live Preview Context Menu**:
  - Right-click images to align **Left**, **Center**, or **Right** using standard `<p align="...">` syntax.
  - Synchronized 100% with Word export (`.docx`) through `WD_ALIGN_PARAGRAPH`.
- **Interactive Image Sizing Dialog**:
  - Quick scale presets (`25% Small`, `50% Medium`, `75% Large`, `100% Original`, and `Custom W/H`) with aspect ratio locking.
  - Click-outside dismissal and safe overlay lifecycle management.

### 🗂️ Studio Workspace & Multi-Tab Architecture
- **Activity Bar & File Explorer**:
  - 48px vertical dock with vector icons and customizable Left/Right docking.
  - Recursive directory tree with lazy loading, async I/O, inline real-time file search filter, and recursive *Collapse All Folders*.
- **Quick Open File Switcher (`Ctrl+P`)**:
  - Blazing-fast fuzzy search modal palette across the workspace with full keyboard navigation.
- **Draggable Multi-Tab Workspace**:
  - Drag-and-drop tab reordering (`ft.Draggable` & `ft.DragTarget`) with animated `ProgressRing` loading indicator.
  - Tab management shortcuts: `Ctrl+Tab` / `Ctrl+Shift+Tab`, `Ctrl+T`, `Ctrl+W`.
  - Per-tab draft sessions (`drafts/{tab_id}.md` & `tab_session.json`), isolated image caches, and 0ms RAM preview hydration.

  - Win32 `SHFileOperationW` Recycle Bin deletion (zero data loss).
