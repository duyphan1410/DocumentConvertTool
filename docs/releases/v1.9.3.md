# 🏛️ Release Notes — v1.9.3: Tesseract OCR Portable Bundling & Supply Chain Security

## ✨ What's New in v1.9.3

### 👁️ Out-of-the-Box Tesseract OCR Portable Engine
- **Fully Self-Contained OCR Engine (`assets/tesseract/`)**:
  - Automatically bundles lightweight, fully functional Tesseract OCR 5.4.0 (`tesseract.exe` + 21 optimized runtime DLLs).
  - Includes Vietnamese (`vie.traineddata`), English (`eng.traineddata`), and Orientation Detection (`osd.traineddata`) language packs by default.
  - Zero manual installation required on fresh client machines — scanned PDF conversion works immediately out of the box.
- **DWARF Debug Symbol Stripping (96.7% Size Reduction)**:
  - Removed 92.66 MB of redundant MinGW DWARF debug symbols from `libtesseract-5.dll` (reduced from 96.77 MB down to 3.14 MB).
  - Shrinks the entire uncompressed OCR engine to only 35.2 MB, and the compressed archive to **~15.3 MB**, completely preserving full OCR fidelity and execution speed.
- **Robust 4-Tier Binary & Tessdata Resolution Hierarchy**:
  - **Binary**: `TESSERACT_CMD` environment variable override ➔ Bundled portable asset (`assets/tesseract/tesseract.exe`) ➔ System `PATH` ➔ Standard Windows system directories.
  - **Tessdata**: `TESSDATA_PREFIX` environment variable override ➔ Bundled `tessdata` (verified with `vie.traineddata` guard) ➔ `%APPDATA%\DocConvert\tessdata` ➔ directory adjacent to binary.

---

### 🛡️ Supply Chain Security & Automated Integrity Verification
- **Two-Layer Cryptographic SHA-256 Checksum Audit**:
  - Pinned exact SHA-256 hashes for the master portable archive and all 27 individual extracted PE binaries and language models in [`scripts/tesseract_manifest.json`](file:///scripts/tesseract_manifest.json).
  - Strict 2-layer verification ensures fail-hard abort (`exit 1`) if any network corruption, partial download, or supply chain tampering is detected.
- **Trusted Domain Lockdown & Network Resilience**:
  - Download endpoints are locked down to the official repository releases domain (`https://github.com/duyphan1410/DocumentConvertTool/releases/download/assets-tesseract-v1/`).
  - High-throughput chunked streaming (512 KB buffers) with browser User-Agent headers and automatic 3-attempt backoff retry logic.
- **Zip Slip Path Traversal Defense**:
  - Sanitizes and validates every archive member destination path before extraction, neutralizing arbitrary file overwrite risks.

---

### 🐛 Critical Bug Fixes & Bilingual Localization
- **Fixed Missing Dependency Error Enum**:
  - Resolved runtime `AttributeError: type object 'ErrorCode' has no attribute 'DEPENDENCY_MISSING'` and `FILE_CORRUPTED` in scanned PDF OCR (`pdf_scan_module.py`) and audio transcription (`audio_module.py`).
- **Complete Bilingual Multi-Language Support (EN/VI)**:
  - Added full i18n localization keys (`ocr.missing_tesseract_*`, `ocr.missing_langpack_*`, `ocr.cannot_open_pdf_*`, `audio.missing_whisper_*`, `audio.transcription_failed_*`, `audio.no_speech_detected`) across `src/i18n/locales/vi.json` and `en.json`.
